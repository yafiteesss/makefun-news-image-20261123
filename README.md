A one-image summary of the world's news of Monday 23 November 2026, drawn from scratch with the Python standard library: six verified stories from that day — Jensen Huang's return as Nvidia CEO, a suspected Russian drone over Poland, Ukraine sinking a Russian warship off Libya, Trump's new Iran sanctions, Tyson Fury's schizophrenia revelation, and the Thai-Cambodia truce holding. A small 5x7 bitmap font, flat geometric pictograms and a hand-rolled PNG encoder render a 1024x1024 poster; no network, no photos, two runs write byte-identical files.

## Run it

```sh
python3 main.py
```

This writes `out/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set, `/output/entry.png` on the grader).
